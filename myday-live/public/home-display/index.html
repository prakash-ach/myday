      Keeping the screen on

      Android tablet or phone

      For a permanent display, install the Home Display Android app (android/ folder). It holds the screen on, can turn the panel off and on, and can be set as the home app so it starts after a power cut.

      In a browser only: Settings, Display, Screen timeout, set to the longest value. Turn on Developer options, then “Stay awake” keeps the screen on while charging.

      iPad or iPhone

      Settings, Display & Brightness, Auto-Lock, Never. Add this page to the Home Screen and turn on Guided Access to keep it in front.

      Computer, Chromebook or Raspberry Pi

      Set display sleep to Never in power settings. On a Raspberry Pi, disable screen blanking in raspi-config and run Chromium with --kiosk.
